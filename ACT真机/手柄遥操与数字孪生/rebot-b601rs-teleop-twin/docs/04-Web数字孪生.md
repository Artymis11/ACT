# Web数字孪生：实物动，电脑三维模型跟随

## 这个页面显示什么

页面是一套**由实测反馈驱动的三维监看界面**。它显示机械臂模型、七轴原生角度、控制目标、当前阶段、手柄连接、速度档位、MIT平均发送频率和温度回读。

当前交付的是姿态同步显示，不运行接触、摩擦、重力、碰撞和抓取力的完整物理仿真。也没有把模型的运动当作实体已经成功抓取的证据。

## 打开方式

- 想同时启动控制与显示：`一键遥操与数字孪生.cmd`。
- 机械臂已经由当前仓库控制，只需加显示：`仅打开数字孪生.cmd`。
- 只想查看显示程序、暂不接臂：也可单独开数字孪生，页面会显示等待或最后记录，不会自动使能。

地址通常是`http://127.0.0.1:8767/`。已有其他服务占用端口时自动选择8768～8777；不要只凭旧地址推断当前服务是否启动，以窗口输出为准。

服务只监听本机回环地址。默认不对局域网或公网开放，不依赖在线网站来转发机械臂状态。

## 三层姿态要分清

| 内容 | 数据来源 | 能说明什么 |
| --- | --- | --- |
| 实体模型 | `positions_native_rad` | 当前会话保存的真实电机角反馈 |
| 控制目标影子 | `transport.last_targets_rad` | 控制器快照中的目标；高频后端还会插值，不能等同每帧实际编码发送位置 |
| 本次起点 | 会话启动时的七轴新实测位置 | A/Y返回目的地；不等同模型固定零点 |

实体模型不由摇杆量直接驱动，也不拿目标值代替实测值。目标影子为半透明浅蓝色，与实测差异很小时自动隐藏。

## 常用视图操作

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 旋转观察方向 |
| 滚轮 | 放大／缩小 |
| 右键拖动 | 平移视图 |
| 立体／正视／侧视／俯视 | 切换预设相机方向 |
| 适应视图 | 重新居中显示模型 |
| 叠加目标姿态 | 显示／隐藏控制目标影子 |
| 地面网格 | 显示／隐藏参考网格 |
| 暂停画面 | 冻结模型与角度显示，**不暂停实物** |
| 继续显示 | 重新跟随当前有效姿态 |

键盘也可操作。用Tab或点击聚焦三维区域后：方向键旋转；Shift＋方向键平移；＋／－缩放；Home适应视图。页面的“模型与操作说明”中有同样提示。

## 状态标识

| 页面提示 | 含义 |
| --- | --- |
| 等待遥操反馈 | 尚未找到可用真实状态；参考零姿态不代表实物在零位 |
| 实测反馈同步中 | 状态新鲜且控制器未报告故障，模型跟随实测快照 |
| 会话已结束／最后姿态 | 正常结束或外部接管后，保留最后记录 |
| 控制器故障／最后姿态 | 原控制器报告故障；画面不能被当作仍实时跟随 |
| 数据已过期／最后姿态 | 文件超过750ms未更新 |
| 显示服务未连接 | HTTP服务暂不可访问；页面自动重试，不发机械臂停止或恢复命令 |
| 温度回读数值异常 | 字段超出显示合理范围；不把异常编码值称为实测高温 |

“状态更新×ms前”是文件快照更新时间，**不是每个电机独立的CAN往返延迟**。故障分支仍可能频繁写日志，单凭文件更新快不能证明真实反馈正常。

非实时状态下，同一会话的后续日志不再推动模型和关节表格。新的真实控制会话产生后自动选择；同会话恢复有效实时状态后才重新跟随。

## 为什么不再开一个MotorBridge窗口读取CAN

当前控制器已经拥有CAN连接。数字孪生从它写出的状态文件读取数据，不创建第二个硬件控制器，不打开Gateway，不增加额外电机读写。

```text
现有CAN所有者
  ├─ 按既有节奏控制电机
  ├─ 接收实测位置/状态
  └─ 原子写 status.json
           ↓
     独立只读HTTP服务（约20Hz读取）
           ↓
     浏览器整组姿态短时插值
```

关闭浏览器、切换视角或暂停画面，都不会因此失能机械臂。结束机械臂控制仍使用A／B等原手柄规则。

## 模型来源与角度换算

RS URDF和网格来自[Seeed文档收录项目](https://wiki.seeedstudio.com/rebot_arm_b601_rs_web_simulator_developer_guide/)，通过固定版本和SHA-256清单获取。本地中文监看壳没有执行该项目的ROS2／硬件控制生命周期。

- J1～J6默认`q_model=q_native`。关节旋转方向已写在URDF的轴定义中，不再按某次演示的正负符号重复翻转。
- 显示端忽略URDF的角度夹持，允许呈现实测的小负误差或略超软件余量的姿态，不偷偷修正反馈。
- J7沿用本机已识别的MotorBridge显示比例：0～4.71rad映射到每指0～50mm模型位移。
- 夹爪显示比例与手柄170°软件上限是两个不同设置；不会强行把“软件最大目标”拉伸成“模型完全张开”。
- 该换算不是实测开口宽度；模型装配零位对齐也没有通过这轮软件检查自动完成。

配置在`digital_twin/model_mapping.json`。其中符号／零偏仅影响显示；修改后刷新网页，不会写回电机或改变遥操运动。

## 资源、路径与扩展

数据源固定为同一仓库中的`teleop/runtime/live_<会话ID>/status.json`。服务扫描最新会话，不沿用旧日志作为新会话起点。

如果以后需要轨迹、相机或数据集记录，优先读取同一控制器的状态与实际发送证据，保留采样时间和坐标定义。当前页面没有LeRobot数据集导出功能，不把监看功能称为完整的数据采集管线。
