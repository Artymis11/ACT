# 设备、环境与连接说明

## 1. 设备到底是哪一款

本项目面向 **reBot Arm B601-RS**：六个旋转关节，加一个由第七台电机驱动的夹爪。资料中有时与Arm102主臂一起出现，本项目的被控实体是B601-RS，不需要Arm102主臂参与。

| 关节 | 电机 | CAN ID | 数组位置 | 主要作用 |
| --- | --- | --- | --- | --- |
| J1 | RobStride RS06 | 1 | 0 | 底座旋转 |
| J2 | RobStride RS06 | 2 | 1 | 肩部 |
| J3 | RobStride RS06 | 3 | 2 | 肘部 |
| J4 | RobStride RS00 | 4 | 3 | 腕部 |
| J5 | RobStride RS00 | 5 | 4 | 腕部 |
| J6 | RobStride RS00 | 6 | 5 | 腕部 |
| J7 | RobStride RS00 | 7 | 6 | 夹爪开合 |

固定反馈主机ID为 `0xFD`（十进制253），CAN波特率1Mbps，标准CAN扩展帧。代码当前假设ID1～7唯一，不会自动猜测、更改或重排电机ID。

## 2. 手柄

本次使用 **北通斯巴达2无线版**。程序读取的是Windows XInput标准化状态，所以关键条件是操作系统能以XInput方式识别手柄。

- 用手柄实际配套的无线接收器或其支持的连接模式连接电脑。
- 如存在多种协议模式，请选能够在Windows中提供XInput输入的模式。
- 不把“蓝牙已经配对”直接当作“XInput已可读”；不同模式的结果可能不同。
- 默认固定读取XInput槽位0，不在断连后自动切换到另一只手柄。
- 需要其他槽位时，命令行可指定 `--slot 1`、`2` 或 `3`；桌面入口默认0。
- 手柄不直接接CAN，也不直接与电机无线通信：所有运动指令由电脑程序转发。

本项目没有核实手柄包装上的完整SKU、不同批次固件和所有连接模式，因此不声称任意“斯巴达2”产品都无需调整即可兼容。

## 3. USB-CAN适配器

当前真实后端是 Windows **PCANBasic** 接口，使用首个USB通道 `PCAN_USBBUS1=0x51`。

本次电脑的实际通信链路由该接口建立。现场适配器外壳曾出现 `UTC-T01` 字样，但外壳型号不能证明所有同名适配器都与PCANBasic兼容。选择替代设备时，以其官方驱动/API是否支持当前接口为准。

特别注意：普通串口USB-CAN、SLCAN、CANable及其他厂商专有USB-CAN协议，并不因接口外形相似就能使用本后端。Linux SocketCAN的`can0`也不是当前Windows通道的配置方式。

### 驱动与DLL

1. 安装适配器的官方Windows驱动。
2. 从 [PEAK-System PCAN-Basic官方页面](https://www.peak-system.com/products/software/development-packages/pcan-basic/?L=1) 获取匹配的x64开发运行库。
3. 确认使用的是 **x64 PCANBasic.dll**，不是32位版本。
4. 在项目根目录执行：

```powershell
py -3.12 tools/bootstrap.py --pcan-dll "<PCAN-Basic安装目录>\x64\PCANBasic.dll"
```

脚本只检查PE架构、复制文件并计算哈希，不打开CAN、不初始化电机。DLL及其本地哈希清单被Git忽略，不应上传仓库。

也可以在当前PowerShell设置：

```powershell
$env:REBOT_PCAN_DLL = "<PCAN-Basic安装目录>\x64\PCANBasic.dll"
py -3.12 tools/bootstrap.py
```

## 4. 电源与接线

本次B601-RS使用48V电机主电源。**USB只负责适配器与电脑通信，不会给整条机械臂提供电机所需主电源。**

```text
无线手柄 ── 无线接收器 / XInput连接 ── Windows电脑
Windows电脑 ── USB ── PCANBasic兼容USB-CAN ── CAN_H/CAN_L/GND ── B601-RS
48V主电源 ─────────────────────────────────────────────── 电机电源链
```

CAN_H、CAN_L与信号地按设备接线说明对应连接，终端电阻按总线拓扑配置；电机供电端与CAN信号端是不同接口。先检查实际接线，不能把“USB已插入”和“电机已通电”混为一件事。

## 5. 软件环境

| 项目 | 要求／说明 |
| --- | --- |
| Windows | x64；建议使用Windows 10/11的正常桌面环境 |
| Python | 推荐3.12 x64；本次回归使用3.12.14 |
| PowerShell | Windows PowerShell 5.1或更新版本 |
| 浏览器 | 支持WebGL的Chrome、Edge或同类现代浏览器 |
| 网络 | 首次资源准备需要访问GitHub raw资源；准备完成后默认运行不需要外部网络 |
| Node.js | 只用于可选的前端JavaScript检查，不是页面运行依赖 |
| pip／npm | 默认运行不需要安装额外包或构建前端 |
| ROS2／Ubuntu | 默认Windows路线不需要 |
| MotorBridge Gateway | 默认控制入口不需要启动；不要同时打开第二个硬件控制器 |

启动器优先使用项目`.venv`，其次使用`REBOT_PYTHON`，再尝试Python Launcher与系统Python。若自动查找失败，可设置：

```powershell
$env:REBOT_PYTHON = "<你的Python目录>\python.exe"
.\run.ps1 -Mode all
```

## 6. 第一次准备

```powershell
py -3.12 tools/bootstrap.py
py -3.12 tools/check.py
```

准备程序下载固定版本文件并核对SHA-256；下载失败会报错，不会悄悄切换到最新分支继续运行。参考源码和三维资源存放于本地`vendor/`忽略目录。

首次真实使能前，操作者应已了解当前机械臂装配、零位、负载及支撑状态。此仓库不会通过运行安装脚本替你校零、写Flash或进行机械动作检查。
