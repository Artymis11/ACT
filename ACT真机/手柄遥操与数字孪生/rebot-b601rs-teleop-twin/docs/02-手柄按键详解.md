# 手柄按键完整操作手册

## 先分清三个概念

**使能**：电机进入能够主动控制、保持姿态的状态。它不等于“已经开始移动”。

**回零**：七轴控制目标回到原生角0。由B触发。

**回本次起点**：回到你这一次按X开启会话时，电脑实际读到并保存的七轴姿态。起点可能不是0；A与Y使用这个起点。

例如，本次启动时J2=30°、J3=45°：Y返回30°/45°并保持使能；A长按3秒返回30°/45°后失能；B返回0°/0°后失能。

## 完整启动顺序

1. 接好USB-CAN，打开手柄和机械臂主电源。
2. 打开控制程序，初始显示`disabled_waiting_for_X`。
3. 此时程序尚未打开CAN。松开LB、摇杆回中、方向键松开、LT/RT放开，松开其他功能键。
4. **新按一次X**。如果启动前已经一直按住X，必须先松开再按。
5. 程序读取当前七轴实际姿态，保存为这次会话起点，再进行使能与反馈确认。
6. 进入ready后，按住LB，再推动对应摇杆／方向键／扳机。

## LB：手动点动的按住许可

位置：左肩键，通常在LT扳机前方。

- 所有摇杆、方向键、夹爪点动都需要按住LB。
- 松开LB时，取消手动点动意图，电机继续保持控制，不直接失能。
- LB不是急停按钮，也不执行回零。
- 先按住LB再推摇杆，或在已就绪状态下保持输入并按住LB，都会产生对应意图。
- 从断连、过期或重新启动状态恢复时，要先释放LB、回中，完成恢复流程后再操作。

## 摇杆、方向键和夹爪逐项说明

所有“增加／减少”均指**电机原生角度数值**。不同关节的机械安装方向不同，不能统一称为从同一视角观察的顺时针／逆时针。

| 操作（同时按住LB） | 控制对象 | 原生角变化 | 松开后的行为 |
| --- | --- | --- | --- |
| 左摇杆向右 | J1，电机1，底座 | 增加 | 该轴停止点动，其他轴可继续 |
| 左摇杆向左 | J1 | 减少 | 同上 |
| 左摇杆向上 | J2，电机2，肩部 | 增加 | 同上 |
| 左摇杆向下 | J2 | 减少，最低软件目标0° | 同上 |
| 右摇杆向上 | J3，电机3，肘部 | 增加 | 同上 |
| 右摇杆向下 | J3 | 减少，最低软件目标0° | 同上 |
| 右摇杆向右 | J4，电机4，腕部 | 增加 | 同上 |
| 右摇杆向左 | J4 | 减少 | 同上 |
| 方向键向上 | J5，电机5，腕部 | 增加 | 同上 |
| 方向键向下 | J5 | 减少 | 同上 |
| **方向键向左** | **J6，电机6，腕部** | **增加** | 同上 |
| **方向键向右** | **J6** | **减少** | 同上 |
| RT右扳机 | J7，电机7，夹爪 | 增加，张开 | 停止继续开合 |
| LT左扳机 | J7 | 减少，闭合 | 停止继续开合 |

J6的正方向特意列粗：当前映射为“左增加、右减少”，请以表格为准。

### 能否多个关节一起动？可以

- 左摇杆斜推：J1与J2同时产生意图。
- 同时推动左右摇杆：可以同时控制J1～J4。
- 方向键按斜向：J5与J6可以同时产生意图。
- 摇杆、方向键、一个扳机可以组合：七轴控制意图是逐轴计算、整组提交的，没有“每次只能选一个关节”的限制。
- 单独释放某个轴的输入，只取消该轴的手动运动，其他有效输入继续生效。

两个扳机同时超过死区时，夹爪意图为保持，不用“压得更深的一侧”抢占。方向键上下同时有效会抵消J5；左右同时有效会抵消J6。

## X：使能／恢复

### 未使能、正在等待X时

释放LB，摇杆／方向键／扳机回中，再按一个新的X按下沿。程序创建新控制会话，读取新实测起点，并按当前姿态启动控制。不会因按X自动回零。

### 当前会话暂停或可恢复反馈过期时

先让输入回中并释放LB，再新按X申请恢复。只有实际反馈已经恢复新鲜、模式和运行状态满足要求、没有锁存真实电机报警等情况才允许恢复。

恢复同一会话不会把起点重新定义为当前姿态，也不会把积压的旧点动目标补发出去。

### X不能做什么

- 不能强行清除真实电机报警。
- 不能把仍缺失的反馈变成有效反馈。
- 不能替代主电源、CAN接线和驱动。
- 当前Start键不再承担恢复功能。

## A：连续长按3秒，回本次起点后失能

这是“返回本次启动位置并结束”的操作。

1. 按下A期间停止手动点动意图。
2. 连续有效长按达到3秒后，请求返回本次固定起点。
3. 返回目标轨迹与停留流程完成后，按现有正常结束流程失能并关闭CAN。
4. 监督程序继续运行，重新等待下次X；下次X才建立新起点。

**短按A不会失能。** 长按不足3秒松开后，不会在稍后补触发；下一次长按重新计时。

补充规则：

- A长按计时不要求先松LB；程序会停止点动，不把A期间摇杆输入转成运动。
- A释放、输入断连、无效输入或异常采样间隔会中断／重置计时。
- 启动前已按住A，不直接算作一次新长按。
- A与X、Y、RB冲突时不按正常A长按触发。
- A返回中按B，可以改为B的回零停机目的地。
- A不足3秒松开后，如仍按住LB且摇杆偏转，正常遥操意图可重新产生；不要把短按A当作持续暂停。

## B：缓慢回零后失能

这是“回原生全零并结束”，目的地与A不同。

- 七轴目标平滑返回0，包括夹爪电机。
- 复用返回曲线、最短返回时长与停留流程，避免普通停机在任意弯肘姿态直接卸力。
- B优先级最高，可覆盖A的回起点结束请求。
- 完成正常停机后关闭CAN，并回到等待X。
- 不将软件目标轨迹结束称为“每个电机精确实测0°已经验收”。

### 遇到故障时为什么B可能不回零？

反馈不可用或通信故障时，程序不盲目执行返回，不能保证B完成回零。热保护另有例外：达到热断开条件时，现有控制入口会执行紧急失能，不等待先回零。因此不能把正常返回流程理解为所有故障下都先回零、再失能。此时应保留现场和错误记录，不能把“B没有产生运动”解释为按键未连接。具体处理见[故障排查](07-故障排查.md)。

## Y：只回本次起点，保持使能

松开LB、全部回中后新按Y。程序返回本次固定起点，完成后继续保持使能；这不是结束会话。当前会话的起点不变，也不关闭CAN。

如果想回起点后结束，用A长按3秒；想回零后结束，用B。

## RB：切换速度档

松开LB，摇杆／方向键／扳机回中后，新按RB：

```text
25% → 50% → 100% → 25% → …
```

桌面启动默认25%。各轴在摇杆／扳机满幅时的目标速度上限如下；方向键只有开／关输入。

| 关节 | 25%档 | 50%档 | 100%档 |
| --- | --- | --- | --- |
| J1 | 7.5°/s | 15°/s | 30°/s |
| J2 | 5°/s | 10°/s | 20°/s |
| J3 | 5°/s | 10°/s | 20°/s |
| J4 | 7.5°/s | 15°/s | 30°/s |
| J5 | 10°/s | 20°/s | 40°/s |
| J6 | 15°/s | 30°/s | 60°/s |
| J7 | 15°/s | 30°/s | 60°/s |

这是软件目标速度上限，不是已验证的机械最大能力，也不代表每个瞬间的实测速度。

### 为什么半推摇杆感觉很慢？

当前死区为0.12，之后使用立方曲线：

```text
若 |x| < 0.12：输出0
否则 u = sign(x) × (|x| − 0.12) / 0.88
摇杆意图 = u³
关节目标速度 = 意图 × 该轴满档速度 × 当前档位
```

例如半幅输入`x=0.5`，曲线输出约0.0805；J2在25%档约0.40°/s。因此“小推杆”比“满推杆”慢很多。小速度下还会受到协议位置编码分辨率影响，这与只能单轴运动是两回事。

## 其他键

- Start：当前没有使能或恢复功能。
- Back：当前没有配置控制功能。
- 左／右摇杆按下：当前没有配置控制功能。
- 系统／Guide键：不作为本项目运动命令；其系统行为由Windows和手柄驱动决定。
- Esc、Ctrl+C：运行中请求与B相同的缓慢回零停机；等待X阶段可退出监督程序。

## 120秒无操作

120秒没有有效操作者活动时，请求B式缓慢回零后失能。手柄仍在发送静止数据包不会无限续期；死区内噪声也不算持续运动操作。

有效运动意图或新按键边沿可刷新活动时间。输入断连时先停止点动，不等120秒才停止运动意图；“输入丢失停止点动”和“无操作自动结束”是两个不同机制。

## 三个完整例子

### 移动底座并调整肘部

X启动就绪 → 按住LB → 左摇杆左右控制J1，同时右摇杆上下控制J3 → 松摇杆或松LB停止点动。

### 回到本次抓取准备位置后继续

松LB并全部回中 → 按Y → 等返回完成 → 再按住LB继续操作。起点仍是本次启动实测位置。

### 结束操作

选择A长按3秒或B → 等待返回及正常结束完成 → 程序重新等待X → 再决定重新开始，或退出后关闭主电源。
