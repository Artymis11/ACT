# ACT4 真机抓放 · 2026-11-20 封存版

这套工程用主从臂采集双摄示教，在 AutoDL 训练并运行 ACT 策略，最后由 Windows 上的 SenseCraft 客户端执行返回的动作块。任务是抓起红色方块并放进盒内。

发布基线为低学习率 8,000 步权重、两路 RGB224、当前七轴、50×7 云端动作块、本机 60 Hz 下发、J1–J6 以 165°/秒限速插值并启用系数 0.01 的时间集成。11 月 20 日封存了四轮试验。第 1 轮的双摄确认红块被夹起并留在盒内。
