## 同帧离线复测

[回放样本](rpc_fixture/)为第 0 集第 0 帧。两张无损 PNG 与历史 RPC 的原始 RGB224 字节哈希一致，七轴状态和 350 个云端动作值取自已封存的 RPC 响应。

在已安装 LeRobot 0.6.1 和模型处理器的环境中运行：

```bash
python evaluation/replay.py --model local/model/pretrained_model --device cpu --atol 0.002
```

该入口检查 11 个模型文件、两路像素 SHA、动作有限性和 50×7 输出。CPU 对照以反归一化动作坐标的绝对误差评估，本次最大误差为 0.00152，低于 0.002。历史同 A800 回放另行记录逐值相同的结果。 [发布验证](release-validation.json)

## 评测记法

- **抓放**按双摄标记接近、闭爪、物块离桌、搬运、入盒与撤爪。夹爪或关节目标日志提供时间位置，实际持块与入盒以视频为准。
- **轨迹**分别画云端动作块、已发目标和实测反馈，同一把时间尺定位轨迹折返、停顿或延迟。可分别统计 J2/J3 的快速折返与 J7 的闭合时序。
- **传输**固定同一权重、A800 与双向压缩 SSH 做 24 对匹配回放。原图上传再缩图的配对中位增量为 **108.8 ms**，两路 RGB224 与每对 350 个动作值逐一相同。计时从发送观测到客户端拿到动作，服务端 GPU 前向耗时需单独比较。 [传输对照摘要](transport-ab.json)

需要重绘双摄与七轴成片时，从 [render_inference_trial_video.py](../autodl/render_inference_trial_video.py) 加载同轮的两路视频、帧时钟和派发日志。
