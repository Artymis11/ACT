# 7. 项目历程与方法论

## 从试采到封存

| 阶段 | 做法与留下的证据 |
| --- | --- |
| 链路打通 | 由本地公开基线验证接口，实际确认主从臂校准、PCAN 与 RealSense 双摄。先录 ACT2 的 20 集，再形成 ACT4 的 60 集。 |
| 数据与训练 | 统一双摄 RGB224，保留 54/6 划分。三帧均值作用于示教动作标签，二阶差分正则作用于模型训练。保留原标签对照、归一化统计和种子。 |
| 选权重 | 比较 8,000、30,500 与 80,000 步的原标签多步误差。发现训练损失还在下降、留出多步误差已进入平台。8,000 步进入实机对照。 [指标](../training/) |
| 从跳变到平稳执行 | 用真实已发的位置目标作为下一拍的锚点，以 165°/秒限制六轴平滑过渡。在 60 Hz 通常一拍最多约 2.75°，降低块间目标跳变。 |
| 折返的定位 | 在固定观测和下发时钟下回放相邻云块，比较对同一未来步的目标。J2/J3 曾出现明显反向重规划，即使下发节拍稳定也会有回摆。 |
| 动作时间集成 | 对同一未来步的多份预测加权，只合成 J1–J6。封存系数为 0.01，J7 继续沿用原加权队列。13:30 已有同权重、关闭时间集成的顺畅实机片段。15:52 封存版第 1 轮完成入盒，各轮的摆位与启动条件一起保留。 |
| 摄像头与延迟 | 固定双摄视角和起始姿态，按同一像素、同一七轴做换图与重放。把缩图放在本机，实录回放测出 108.8 ms 的配对中位延迟差。 |

## 调试中学到的事

- **拆开三个时钟。** 用相机和实测反馈记观测，云块记计划，本地已发记执行。先对齐一条完整失败轨迹，再逐段测画面遮挡、观测年龄、动作折返与驱动是否实际跟随。
- **一次只切一个因素。** 固定帧、权重和服务比较传输。固定时序和云块比较调度。实机试次尽量固定摆位、第一帧和起始轴角，用相邻轮对照建立归因。
- **保留有取舍的方案。** 六轴历史 5,000 步是另一个 13 维模型。融合版 J2/J3 回拉限制在七轮离线回放中压低部分峰值，现场效果仍需独立验收。成片和离线分析按版本标记。
- **抓取与轨迹分别验收。** 夹爪到位和曲线顺滑都能从记录测量。持块、抬起和红块最终位置由画面确认。轻抬验块与自动复抓有离线验证记录，整条复抓流程仍待真机正例。
